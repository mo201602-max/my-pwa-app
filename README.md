# PWA共通テンプレート Ver.1

HTML + CSS + JavaScriptで作ったWebページを、Androidスマートフォンのホーム画面からアプリのように起動するための最小テンプレートです。

## ファイル構成

- `index.html` : 画面
- `style.css` : デザイン
- `app.js` : アプリの処理、インストール操作、更新通知
- `manifest.json` : アプリ名・アイコン・起動方法
- `service-worker.js` : オフライン用キャッシュと更新
- `icons/` : アプリアイコン

## まずPCで確認する

PWAのインストールとService Workerは、原則としてHTTPSまたはlocalhostで動作します。
HTMLファイルを直接ダブルクリックするだけでは、PWA機能を正しく確認できません。

簡単な方法：
1. このフォルダをPCに展開する
2. VS CodeなどのローカルWebサーバー機能で開く（例：Live Server）
3. ブラウザで表示を確認する

## GitHub Pagesで公開する

1. GitHubにログインし、新しいリポジトリを作る
2. このフォルダ内のファイルをリポジトリの直下にアップロードする
3. リポジトリの Settings → Pages を開く
4. Build and deployment で Deploy from a branch を選ぶ
5. Branch を `main`、フォルダを `/(root)` にして Save
6. 公開URLが表示されるまで待つ

GitHub Pagesの公開リポジトリは、原則として誰でも閲覧できます。HTML/JavaScript内にパスワード、秘密情報、個人情報を埋め込まないでください。URLを知る人だけに限定したい用途には、そのまま使わないでください。

## Androidにインストールする

1. 公開URLをAndroidのChromeで開く
2. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選ぶ
3. 確認画面で追加する
4. ホーム画面のアイコンから起動する

ブラウザやOSのバージョンにより、表示名・操作は多少異なります。

## オフライン動作を確認する

1. 一度オンライン状態で公開ページを開く
2. Service Workerの登録が完了するまで少し待つ
3. アプリを閉じ、機内モードなどで通信を切る
4. ホーム画面のアイコンから起動する

初回アクセス前のオフライン起動はできません。

## 別のアプリに作り替える

1. `index.html` の画面を目的のアプリに変更
2. `style.css` でデザインを変更
3. `app.js` にアプリ固有のJavaScriptを記述
4. `manifest.json` の `name`、`short_name`、`description`、色を変更
5. `icons/` の画像を差し替える
6. `service-worker.js` の `CACHE_VERSION` を必ず変更する
7. 公開先に上書きアップロードする

### 更新時の注意

`service-worker.js` の `CACHE_VERSION` を変更しないと、古いキャッシュが残る場合があります。
アプリのバージョンを上げるときは、両方を更新してください。

- `app.js` の `APP_VERSION`
- `service-worker.js` の `CACHE_VERSION`

更新通知が表示されたら「更新する」を押すと、新しいキャッシュに切り替わってページが再読み込みされます。

## 保存データについて

サンプルのカウンターは `localStorage` に保存しています。
これは端末・ブラウザごとの保存であり、他の利用者とは共有されません。
アプリのデータ消去やブラウザデータの削除で消える可能性があります。

## Ver.1の範囲・制限

- Android + Chromeを主対象とした基本テンプレート
- iPhoneでもPWAとして利用できる場合がありますが、インストール手順や一部機能は異なります
- カメラ、GPS、Bluetoothなどの端末機能連携は未実装
- ユーザー認証、クラウド同期、プッシュ通知は未実装
- GitHub Pagesは静的サイト公開用です。秘密のアプリ配布やアクセス制限には向きません

## ライセンス

このテンプレートは自由に改変して利用できます。
